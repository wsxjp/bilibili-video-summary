# B站视频速览

一个适用于哔哩哔哩普通视频页面的用户脚本。它会优先读取 B 站已有的 AI 总结；如果没有可用的站内总结，则尝试读取当前分 P 的字幕，并在浏览器本机筛选重点句。

无需填写 AI API Key，也不会自动把字幕发送给外部 AI 服务。

## 功能

- 在视频页面右下角添加「视频速览」面板。
- 优先显示 B 站已有的 AI 总结和章节要点。
- 没有站内总结时，从可读取的字幕中本机抽取重点句，并保留时间戳。
- 查看字幕、点击时间戳跳转到视频对应位置。
- 将摘要复制到剪贴板，或导出为 TXT 文件。
- 将完整字幕和一段总结提示词复制出来，供你手动粘贴到自己选择的 AI 工具。
- 支持粘贴 SRT、VTT、B 站字幕 JSON 或纯文字进行整理。

## 安装

1. 在 Chrome、Edge 等支持的浏览器中安装用户脚本管理器，例如 [Tampermonkey](https://www.tampermonkey.net/)。
2. 打开本仓库中的脚本文件：  
   [bili-video-summary.user.js](https://raw.githubusercontent.com/wsxjp/bilibili-video-summary/main/bili-video-summary.user.js)
3. 在 Tampermonkey 安装确认页选择「安装」。
4. 打开或刷新一个 B 站普通视频页面，例如 `https://www.bilibili.com/video/BV...`。
5. 点击页面右下角的「✦ 视频速览」，再点「一键总结」。

如果打开脚本链接后只看到代码，请确认 Tampermonkey 已启用；也可以在 Tampermonkey 的「添加新脚本」中粘贴脚本文件的全部内容并保存。

## 使用说明

### 自动总结

点击「一键总结」后，脚本会先尝试读取 B 站已有的 AI 总结。如果没有可用结果，则尝试读取当前分 P 的字幕，并在本机整理重点句。

本地整理属于**抽取式摘要**：它从字幕中挑选较重要的原句，不会像生成式 AI 那样改写或推导内容。摘要可能遗漏上下文，请结合原视频判断。

### 查看和导出

- 「摘要」页显示总结与重点句；带时间戳的按钮可跳转到视频相应位置。
- 「字幕」页显示读取到的字幕内容。
- 「复制摘要」复制当前总结。
- 「导出 .txt」下载文本文件。
- 「复制给 AI」会复制字幕和总结提示词。之后需要你手动打开所选 AI 工具并粘贴；脚本不会替你上传。

### 手动粘贴字幕

展开「没有字幕？粘贴字幕或逐字稿」，粘贴内容后选择「总结粘贴的内容」。SRT、VTT、B 站字幕 JSON 和纯文字均可；纯文字没有时间戳。

## 权限与隐私

脚本通过用户脚本管理器向 B 站接口及其字幕资源域名发起读取请求，以获取视频信息、站内总结或字幕。需要时请先登录 B 站。读取到的字幕会留在当前页面内存中；本地抽取在浏览器内完成。只有当你主动使用「复制给 AI」并手动把内容粘贴到其他服务时，该服务才会收到这些内容。

脚本不录音、不上传视频或字幕到外部 AI 服务，也不要求 API Key。用户脚本管理器会显示脚本所请求的域名权限；请只从你信任的来源安装脚本。

## 限制与排查

- 仅适用于 `www.bilibili.com/video/...` 普通视频页面；不支持专栏、直播或其他页面。
- 需要视频有可读取的字幕，或由你手动粘贴字幕。脚本不进行语音识别，也不会从视频音轨生成字幕。
- 某些视频或账号可能没有站内 AI 总结或可读取字幕；登录状态、分 P、网络和 B 站接口变化也可能影响读取。
- 若页面提示无法读取字幕，请刷新视频页面、确认已登录并检查用户脚本管理器是否允许访问 B 站相关域名；也可以改用手动粘贴字幕。
- 自动摘要与字幕由 B 站提供，准确性和可用性可能变化；本机重点句只是原文摘录，不等于完整、无误的总结。
- 长视频的字幕内容较多时，可使用分章节粘贴；发送给外部 AI 的长度限制取决于你所使用的服务。
